# IMXP — Fundraise Deck (design option B)

An alternate presentation of the IMXP *"Immersive Experiences at Global Scale"* fundraise deck.

Same 23 published slides as [imxp-deck](https://github.com/ugla-ctrl/imxp-deck), but wrapped in
the **Midnight Sun deck** interface: a light gradient frame, a rounded shadowed 16:9 stage,
cross-fade transitions between slides, and bottom-center dot navigation.

The slide artwork itself is unchanged (full-resolution 1920×1080 PNG exported from Canva).

## View

```
https://ugla-ctrl.github.io/imxp-deck-v2/
```

## Navigation

- **← / →** (or click left / right) — previous / next slide
- **Space / Page Down** — next · **Home / End** — first / last
- Swipe or tap on touch (left-edge tap goes back) · scroll / trackpad
- Deep-link to any slide with `#<n>` (e.g. `…/#7`)

## Structure

```
index.html   # self-contained viewer, Midnight Sun interface
slides/      # slide-01.png … slide-23.png
.nojekyll
```
